# SDUM-022 / SDUM-023: small-angle CINE test run

Status: revised local implementation, not submitted to the server. Commit and
push are handled by the user. Neither this document nor pushing the branch
restarts the paused experiments. Historical sdum-019/020/021 remain unchanged.

## Scope and reference decision

- SDUM-022: rotate full complex coil images by 0, 1, 3, 5 degrees for the pilot.
- SDUM-023: midpoint step 0 to 3 degrees; prepare 0 to 0 as a numerical control.
- Both: Sub0014 and Sub0047, acc8, VISTA seed8 plus 20 central ACS lines,
  all native slices and cardiac frames. No ranking crop.
- Input comes directly from H5 `kSpace`, never from `dImgC * dMap`.
- Each coil image, including its embedded sensitivity pattern, rotates together.
  This tests a simplified coordinate/coil-image perturbation; it is NOT a
  simulation of a patient moving relative to fixed receiver coils.
- Motion uses increasing acquired-PE order within each cardiac frame, stepping
  after floor(N_acquired/2) lines. All coils/readout points share each line's
  angle. All slices share the trajectory; ACS follows the same timeline. These
  are explicitly hypothetical acquisition events, not recovered scan timestamps.

The implemented simulation reference is explicitly RSS of the complete coil
images: rotated RSS for SDUM-022, original unrotated RSS for SDUM-023. It is NOT
H5 dImgC and is NOT described as a replacement for the project's active benchmark
GT. Before interpreting RSS metrics, inspect the zero-degree model output versus
this reference (including possible coil-combination/intensity differences).
`evaluate --accept-rss-reference` records that this review has been accepted; it
is not an automated proof of reference suitability. No fitted gain is applied.
The old dImgC/dMap consistency probe remains historical diagnostic code, not a
required gate or input generator for this revised simulation.

## Explicit normalization

Preparation requires `--normalization none` or `--normalization rss-max`:

| Choice | Input k-space | RSS reference | PSNR data range |
| --- | --- | --- | --- |
| none | original scale | original scale | original full-case RSS maximum |
| rss-max | divide by original full-case RSS maximum s | same division by s | 1 |

The first controlled test should use **none**, preserving original input scale
and making 0-degree input comparison straightforward. Use the same option for
all conditions, both experiments and all accelerations. Never normalize GT
alone, divide the saved prediction by s again, independently normalize a
prediction, clip arrays for metrics, or reuse the scale of a different case.

The generator computes original RSS from all slices and frames, once per
preparation invocation, and records its maximum and p99.5. None/normalized runs
must use different run roots. Zero-degree k-space is stored exactly after the
specified scale conversion; FFT roundtrip error is checked separately (<=1e-5).
The original H5 remains read-only; dImgC and dMap are not read by this generator.

## Plotting and metrics

Each case's original zero-degree full-volume RSS p99.5 determines the grayscale
vmax, divided by s only in rss-max mode. vmin=0. This fixed window is shared by
all conditions, frames and both experiments for that case. The numerical window
will differ from the previously plotted native dImgC windows because the
reference definition differs. Do not silently reuse those dImgC limits here.

Error vmax is an explicit `--error-fraction` times the original reference range
(or 1 in rss-max mode). For example 0.2 is an explicitly chosen display fraction,
not an adaptive normalization. Select it once from pilot inspection and keep it
fixed across later comparisons; use a new review id if changing it. The script
records grayscale/error saturation fractions, exact windows and prediction hashes.

Every slice and every frame is plotted in pages of at most five time frames,
with RSS reference/reconstruction/absolute error rows and colorbars. Display is
native PE rows / FE columns, origin lower, nearest interpolation, equal pixel
aspect; no anatomical orientation or physical pixel spacing is inferred.

Metrics use unmodified arrays, full-size and an auxiliary common support (the
intersection of valid supports for 0..5 degrees). PSNR, NRMSE and NMSE are
computed per frame, then averaged within subjects and equally across subjects.
No main/auxiliary independently normalized figures are generated by this script.
Only explicitly requested case/condition pairs are evaluated; incomplete inputs
fail instead of silently dropping cases. Existing reviews cannot be overwritten.

## Execution sequence (not executed by editing or committing)

1. Run synthetic tests locally with numpy/scipy/h5py/matplotlib installed:
   `python -m unittest discover -s tests -p test_sdum_smallangle.py -v`.
2. User commits/pushes. Fetch server branch and verify a clean identical SHA.
3. Set REPO_ROOT, RUN_ROOT, EXPECTED_COMMIT (full SHA), SOURCE_H5_ROOT,
   SOURCE_MASK_ROOT, MODE, NORMALIZATION=none, ACTION=prepare and ANGLES.
   Submit the new wrapper as a CPU job with explicit log paths. Preparation
   generates and validates the inputs only; it never starts inference.
4. Compare generated pose0 and motion0 carriers/GT. Pose0 is the original input
   after its declared scale conversion. Internal FFT gates do not prove source
   dImgC/map consistency and no such claim is made.
5. For a separate 0-degree inference job, set ACTION=infer, ANGLES=0, MODEL_CKPT
   to the reviewed Base checkpoint and submit with --gres=gpu:1. Keep all other
   settings fixed. Compare to an original-input baseline using the same checkpoint,
   code, mask and normalization, and inspect suitability of the RSS reference.
6. After that inspection, run pose ANGLES='1 3 5' and motion ANGLES=3; no automatic
   full-cohort expansion. Existing predictions are refused by the wrapper.
7. Evaluate with explicit --root, --acc 8, --cases Sub0014 Sub0047, --conditions,
   --review-id, --error-fraction, and --accept-rss-reference. Include motion0 as
   the control in SDUM-023. Full cohort and additional angles remain later work.
